# Blush Theory Studio — Burgundy Beauty Shop

A responsive, single-file storefront concept for digital beauty guides, using burgundy, rose, and cream styling.

## Preview locally
Open `index.html` in a browser.

## Publish on GitHub Pages
This project is currently in the `blush-theory/` folder of the existing `Morning-Protocol` repository so the existing root website is not overwritten.

If GitHub Pages is enabled for that repository and serves the root branch, try:
`https://bxzelbalasabas-netizen.github.io/Morning-Protocol/blush-theory/`

If that URL does not load, check Settings → Pages and select the main branch as the source. GitHub Pages configuration and repository permissions may require manual confirmation.

## Before selling real products
- Replace concept product previews with your finished, original PDF files.
- Replace demo buttons with actual checkout/product URLs (for example, your Payhip or Gumroad product links).
- Connect the email form to an email service or replace it with a real free-download link.
- Replace the placeholder contact email and add your own privacy, refund, and terms pages.
- Verify payment and payout availability for your own Philippine account.
- Review commercial-use rights for all photos, fonts, and design assets.

The current cart and signup form are UI demos only. They do not process payments, collect/store email addresses, or deliver files.
